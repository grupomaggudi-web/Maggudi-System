# Maggudi System - ERP Omnicanal con IA

Plataforma SaaS completa de gestión empresarial integrada con capacidades omnicanal, e-commerce, IA y automatización.

## Características Principales

- **ERP Financiero**: Presupuestos, contabilidad, flujo de caja
- **Gestión de Almacén (WMS)**: Inventarios multi-almacén, caducidades
- **CRM**: Gestión de clientes, expedientes digitales
- **E-Commerce**: Catálogo, carrito, múltiples pasarelas
- **IA**: Chatbots, help desk, predicciones
- **Omnicanal**: Sincronización multicanal

## Tech Stack

- **Backend**: Node.js + Express.js
- **Database**: PostgreSQL + Redis
- **IA**: OpenAI
- **Pagos**: Stripe, PayPal
- **Cloud**: AWS S3

## Inicio Rápido

```bash
git clone https://github.com/grupomaggudi-web/Maggudi-System.git
cd Maggudi-System
npm install
cp .env.example .env
npm run dev
```

Servidor disponible en `http://localhost:3000`
